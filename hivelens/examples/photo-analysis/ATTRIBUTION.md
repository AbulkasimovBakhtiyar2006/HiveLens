# Saved photo-analysis example

This is a saved SAM 3.1 + Muse Spark run made on 4 November 2026.
It is replayed without new API calls. Model outputs have not been improved or regenerated.
The two photographs are unrelated public samples, not the same colony or a field trial.
Three days on board, ten frames and earlier history were demonstration inputs.
The original report includes trends and recommendations based on that context; they
must not be interpreted as real observations or advice for a current hive.

## Board and derived images

`board.jpg`, `board_overlay.jpg`, `board_evidence.jpg`, `board_muse_sheet_*.jpg`:
IMG_5582 from Divasón et al. (2023), https://doi.org/10.5281/zenodo.10231845,
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
HiveLens re-encoded the JPEG and added marks, crops and numbered contact sheets.

## Comb and derived image

`frame_1.jpg`, `frame_1_overlay.jpg`: John Pons,
[Frame from hive of honey bee (apis mellifera)](https://commons.wikimedia.org/wiki/File:Frame_from_hive_of_honey_bee_(apis_mellifera).jpg),
[CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/).
HiveLens re-encoded the JPEG and added segmentation marks. These derived images
remain under CC BY-SA 4.0, rather than the repository's code license.

`inspection.json` retains these credits, original measurements and model outputs.
Only provenance fields (`demo_capture`, `source_kind`, `bundled_example`, `provenance`)
were added for distribution. This sample never contributes to live hive status,
historical comparison or the operational metrics CSV.
